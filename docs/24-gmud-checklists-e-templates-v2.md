# Módulo 24: Checklists e Templates GMUD (v2.0)

## 1. Checklist pré-implementação (Dev)
- [ ] Escopo da mudança definido.
- [ ] Impacto mapeado.
- [ ] Risco classificado.
- [ ] Rollback descrito e viável.
- [ ] Janela proposta.

## 2. Checklist PR/Merge
- [ ] PR revisado e aprovado.
- [ ] Testes mínimos executados.
- [ ] Sem falhas críticas no CI.
- [ ] Commit final identificado.

## 3. Checklist HML
- [ ] Deploy em `dev` concluído.
- [ ] Testes funcionais aprovados.
- [ ] Evidência de homologação anexada.

## 4. Checklist de aprovação (Aprovador)
- [ ] Critérios de negócio atendidos.
- [ ] Risco residual aceito.
- [ ] Janela confirmada.
- [ ] Justificativa registrada na GMUD.

## 5. Checklist Go/No-Go (Release)
- [ ] Tag criada.
- [ ] GitHub Release publicada.
- [ ] GMUD `APPROVED`.
- [ ] Monitoramento ativo.
- [ ] Plano de contingência pronto.

## 6. Checklist pós-deploy
- [ ] Smoke passou.
- [ ] Métricas estáveis.
- [ ] Sem incidente crítico.
- [ ] Evidências anexadas.
- [ ] GMUD encerrada.
