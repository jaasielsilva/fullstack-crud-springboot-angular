# Módulo 2: Evolução de Produtos

## Objetivo
Expandir o módulo de produtos que já criamos, transformando-o num catálogo profissional.

## Funcionalidades Planejadas
1. **Categorização:**
   - Criar tabela de `Categorias` no banco.
   - Relacionar Produtos com Categorias (N:1).
   - Adicionar Select/Dropdown de categorias no formulário (Offcanvas).
   
2. **Imagens de Produtos:**
   - Habilitar upload de imagens via MultipartFile no Spring Boot.
   - Mostrar a miniatura da imagem na tabela no lugar do ícone padrão.

3. **Código de Barras/SKU:**
   - Adicionar campo para código único.
   - (Opcional) Leitura de código de barras.

## Integrações
- Atualizar o Dashboard para mostrar a quantidade de produtos por categoria.
