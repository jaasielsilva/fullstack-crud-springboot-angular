# Módulo 6: Financeiro (Contas a Pagar/Receber)

## Objetivo
Controlar o fluxo de caixa da empresa além das vendas.

## Backend (Spring Boot)
1. Criar entidade `TituloFinanceiro` (Descrição, Valor, Data Vencimento, Data Pagamento, Tipo [RECEITA/DESPESA], Status).
2. Gerar Título de Receita automaticamente ao fechar um "Pedido".

## Frontend (Angular 17)
1. Tela com Abas: "Contas a Pagar" e "Contas a Receber".
2. Funcionalidade de "Dar Baixa" (Marcar como pago) informando a data real do pagamento.
3. Indicadores visuais de títulos atrasados (em vermelho).
